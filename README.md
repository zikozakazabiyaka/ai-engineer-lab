# ai-engineer-lab

Learning log: small Python exercises on the way to an AI engineer portfolio.

## What's here

- `count_docs.py`: counts .md files in a folder (given as an argument), prints total size and the 3 largest files
- `greet.py` / `use_greet.py`: demo of `if __name__ == "__main__"` and imports
- `args_demo.py`, `check.py`: experiments with `sys.argv` and types
- `hello.py`: checks the Python interpreter

## How to run

```bash
source .venv/bin/activate
python count_docs.py /path/to/folder
